# 🧟 RottenfleshMod

> Un mod Minecraft (Forge) qui donne enfin une utilité à la chair pourrie !

---

## 📖 Description

**RottenfleshMod** transforme la chair pourrie — cet item inutile qui encombre ton inventaire — en une ressource précieuse. Le mod ajoute de nouveaux items, blocs et mobs liés à la chair pourrie, ouvrant de nouvelles possibilités de craft et de gameplay.

---

## ✨ Fonctionnalités

- 🔄 **Transformation** — Transforme la chair pourrie en ressources utiles
- 🧱 **Nouveaux blocs** — Blocs craftables basique
- ⚔️ **Nouveaux items** — Items inédits
- 👾 **Nouveaux mobs** — Créatures géante

---

## 🔧 Prérequis

| Composant | Version        |
|-----------|----------------|
| Minecraft | *1.12.2*       |
| Forge | *1.12.2*       |
| Java | 8 ou supérieur |

---

## 📦 Installation

1. Télécharge et installe **[Minecraft Forge](https://files.minecraftforge.net/)**
2. Télécharge le fichier `.jar` du mod depuis la page [Releases](../../releases)
3. Place le fichier dans ton dossier `.minecraft/mods/`
4. Lance Minecraft avec le profil Forge ✅

---

## 🛠️ Compilation depuis les sources

```bash
# Cloner le dépôt
git clone https://github.com/ton-user/RottenfleshMod.git
cd RottenfleshMod

# Compiler
.\gradlew build

# Lancer en mode développement
.\gradlew runClient

#Possibilité de lancer en debug pour ajustements en direct (Sauf ressources)
```
